'''大野 元裕'''（おおの もとひろ、[[1963年]]〈[[昭和]]38年〉[[11月12日]] - ）は、[[日本]]の[[政治家]]、[[外交官#日本の外交官制度|外交官]]。[[埼玉県知事一覧|埼玉県知事]]（第61・62代）。[[学位]]は[[修士]]（[[国際大学]]・[[1989年]]）。[[無所属]]<ref>[https://www.pref.saitama.lg.jp/documents/153457/chijikouhou.pdf 令和元年8月25日執行 埼玉県知事選挙公報](PDF). / [https://www.pref.saitama.lg.jp/documents/251011/04senkyokoho.pdf 令和5年8月6日執行 埼玉県知事選挙公報](PDF). : {{accessdate|2025-06-04}}</ref>。

[[日本の国会議員#参議院議員|参議院議員]]（2期）、[[財団法人]][[中東調査会]]研究員、[[外務省]][[国際情報統括官組織|国際情報局]]分析第二課専門分析員、[[在ヨルダン日本国大使館|在ヨルダン大使館]]一等書記官、[[在シリア日本国大使館|在シリア大使館]]一等書記官、[[株式会社]]ゼネラルサービス[[取締役]]統轄本部本部長、財団法人中東調査会[[上席研究員]]、株式会社ゼネラルサービス[[役員 (会社)#専務、常務、執行役、執行役員|専務取締役]]、[[内閣府大臣政務官]]兼[[防衛大臣政務官]]（[[野田内閣 (第3次改造)|野田第3次改造内閣]]）などを歴任。

== 来歴 ==
=== 生い立ち ===
[[埼玉県]][[川口市]]生まれ。[[ライオンズクラブ]]国際理事や[[大野元次郎#大野電機鋳造所|大野電機鋳造所]]社長を務めた[[大野元昭]]の長男として生まれる<ref name=":0">{{Cite web |title=三田紳士録 |url=https://dl.ndl.go.jp/pid/12241576/1/117?keyword=%E5%A4%A7%E9%87%8E%E5%85%83%E6%98%AD |website=dl.ndl.go.jp |access-date=2025-01-25 |author=三田紳士録刊行会 |page=223 |year=1980}}</ref><ref>{{Cite web |title=参議院議員　大野　もとひろ　のページ |url=https://www.oonomotohiro.jp/KARUTA/01/HTML/00.html |website=www.oonomotohiro.jp |access-date=2025-01-25}}</ref>。母は[[ゼネラルサービス]]代表取締役や川口[[商工会議所]]常議員を務める大野洋子<ref name=":0" /><ref>{{Cite web|title=会社案内 {{!}} 株式会社ゼネラルサービス｜埼玉県川口市の総合ビルメンテナンスサービス|url=https://www.generalservice.jp/company|website=www.generalservice.jp|access-date=2026-02-25}}</ref><ref>{{Cite journal |author=川口商工会議所 |date=2019-12 |title=MOVE 12 2019 December Vol.553 |url=https://www.kawaguchicci.or.jp/wp_cci2021/wp-content/uploads/2021/04/move_1912.pdf |journal=MOVE }}</ref>。妹が1人いる<ref name=":0" />。

[[川口市立朝日東小学校]]、[[明治大学付属中野中学校・高等学校|明治大学付属中野中学校]]、[[慶應義塾高等学校]]を経て、[[慶應義塾大学大学院法学研究科・法学部|慶應義塾大学法学部]][[政治学|政治学科]]卒業。[[国際大学]][[国際関係学研究科]]（[[中東]][[地域研究]]専攻）修士課程修了<ref name="profile">[https://www.oonomotohiro.jp/profile03.html 大野もとひろ埼玉県知事 公式ホームページ - 略歴]</ref>。[[1989年]]4月に[[外務省]]に入省し、[[在イラク日本国大使館|在イラク日本大使館]][[専門調査員]]。[[1990年]]より[[在アラブ首長国連邦日本国大使館|在アラブ首長国連邦日本大使館]]専門調査員。[[1993年]]から2年間、[[財団法人]][[中東調査会]]研究員を務める。その後も[[外務省]]国際情報局分析二課専門分析員、[[在カタール日本国大使館|在カタール日本大使館]]専門調査員、[[ヨルダン]]、[[シリア]]の日本大使館で書記官を務めた。また[[1989年]]から国際大学中東研究所非常勤研究員を務めたほか、[[東京大学大学院総合文化研究科・教養学部|東京大学教養学部]]、[[青山学院大学]]大学院でも非常勤講師、[[日本テレビ放送網|日本テレビ]]のコメンテーターを務め、[[2005年]]より5年間、[[防衛省]]防衛戦略委員会委員。[[ニッポン放送]]のコメンテーターとしても活躍。

===埼玉県知事選挙に出馬へ===

日本経済新聞 2019年8月1日</ref>。大野の辞職願提出がこの日になった理由として「[[第25回参議院議員通常選挙|参議院議員通常選挙]]中は議員の半数が欠ける状況となるので、（突発事態が発生した場合など）危機管理上問題があった」ためだったという<ref name="Mainichi 20190801"/>。8月5日付で辞職が許可された<ref>『官報』第66号8頁 令和元年8月7日号</ref>。選挙戦では「上田県政の継承と発展」を前面に掲げて挑んでおり、前知事である[[上田清司]]も応援団長として協力した<ref>{{Cite web|和書|url = https://oonomotohiro.jp/2019/08/09/%E5%9F%BC%E7%8E%89%E7%9C%8C%E7%9F%A5%E4%BA%8B%E9%81%B8%E6%8C%99%E3%80%81%E5%A4%A7%E9%87%8E%E3%82%82%E3%81%A8%E3%81%B2%E3%82%8D%E6%B1%BA%E6%84%8F%E8%A1%A8%E6%98%8E/ |title = 埼玉県知事選挙、大野もとひろ決意表明 |website = 埼玉県知事候補 大野もとひろ 特設サイト |date = 2019-08-09 |accessdate = 2019-10-13 }}</ref><ref>{{Cite news |url = https://web.archive.org/web/20190827005155/https://www.tokyo-np.co.jp/article/saitama/list/201908/CK2019082702000148.html |title = 知事選を振り返って 劣勢覆した大野さん 上田色、前面に選挙戦 |newspaper = [[東京新聞]] |publisher = [[東京新聞社]] |date = 2019-08-27 |accessdate = 2019-10-13 }}</ref>。[[8月25日]]の投開票の結果、[[自由民主党 (日本)|自由民主党]]・[[公明党]]が推薦する[[スポーツライター]]の[[青島健太]]ら4候補を破り、初当選を果たした。選挙終盤まで接戦が報じられ、青島86万6021票に対し、大野92万3482万票と僅差での当選であった{{Efn|歴代の埼玉県知事選挙で最も僅差での当選となっている。}}。なお上田は大野の辞職に伴う[[2019年日本の補欠選挙|補欠選挙]]に立候補し当選、参議院議員に転出したが、大野が参院選の公示前に辞職した場合は第25回参議院選挙の際に埼玉県選挙区の定数を増員する形で合併選挙として行われていたため、参院転出は事実上不可能となっていた。

[[2019年]][[8月31日]]、埼玉県知事に就任<ref>{{cite news|url = https://www.nikkei.com/article/DGXMZO49262450R30C19A8000000/ |title =初登庁前に初仕事 埼玉県の大野新知事、防災訓練視察 |newspaper = [[日本経済新聞]] |date = 2019-08-31 |accessdate = 2019-09-01}}</ref>。

[[2023年]][[8月6日]]投開票の[[2023年埼玉県知事選挙|埼玉県知事選挙]]で2期目となる再選を果たした<ref>{{Cite web|和書|url=http://www.pref.saitama.lg.jp/e1701/r5chijikekka.html |title=埼玉県知事選挙（令和5年8月6日執行）結果|website=[[埼玉県]]庁 公式ホームページ|publisher=埼玉県庁|accessdate=2025-06-07|archiveurl=https://warp.da.ndl.go.jp/collections/info:ndljp/pid/13058516/www.pref.saitama.lg.jp/e1701/r5chijikekka.html |archivedate=2023-10-05|url-status=live|url-status-date=2025-06-07}}</ref><ref>{{Cite news|url=https://mainichi.jp/articles/20230806/k00/00m/010/239000c |title=「信任投票」全国最低の投票率 埼玉知事選、大野元裕氏が再選|newspaper=毎日新聞|publisher=毎日新聞社|date=2023-08-06|accessdate=2023-08-07}}</ref>。

=== 埼玉県知事としての公約・政策 ===
* [[2019年埼玉県知事選挙]]に立候補した際の公約には、[[埼玉高速鉄道]]の[[岩槻駅|岩槻]]延伸、[[東京都交通局日暮里・舎人ライナー|日暮里舎人ライナー]]や[[都営大江戸線]]、[[多摩都市モノレール]]など東京都内が終点となっている路線を埼玉県まで延伸する「あと数[[マイル]]プロジェクト」、[[埼玉県警察|埼玉県警察本部]]の独立庁舎建設を掲げていた。
* [[2019年埼玉県知事選挙]]に先駆けて行われた受動喫煙撲滅機構からの公開質問に対し、喫煙場所の明示や[[分煙]]の徹底に取り組むと回答しているが、[[埼玉県]]独自の受動喫煙防止条例の制定については「（隣接県と）規制に大きな違いが出てしまうことは望ましくない」との理由から、「国でシンプルなルールを定めるべき」として消極的な姿勢を見せている。また、日本初の屋内[[禁煙]]の法令である[[神奈川県]]の[[神奈川県公共的施設における受動喫煙防止条例|受動喫煙防止条例]]についても「県で[[条例]]を制定することの意欲は評価できる」と前置きをしながらも「条例ではなく[[法律|法]]で制定すべき」と批判的に述べている<ref>{{Cite web|和書|title = 候補者へのアンケート(’19年8月25日投開票)埼玉県知事･秦野市･八街市 |url = https://www.tabaco-manner.jp/cate_news/8416/ |website = https://www.tabaco-manner.jp/ |date = 2019-08-22 |accessdate = 2019-08-23 |language = ja |publisher = 受動喫煙撲滅機構}}</ref>。
