'''大井川 和彦'''（おおいがわ かずひこ、[[1964年]]〈[[昭和]]39年〉[[4月3日]] - ）は、[[日本]]の[[政治家]]、[[経済産業省|経産]][[官僚]]。[[茨城県知事一覧|茨城県知事]]（公選第19・20・21代）。[[無所属]]<ref>[https://www.soumu.go.jp/senkyo/senkyo_s/data/syozoku/index.html 総務省 地方公共団体の議会の議員及び長の所属党派別人員調等]</ref>。

== 来歴 ==
[[茨城県]][[土浦市]]生まれ<ref name="profile">[http://k-oigawa.jp/profile/ プロフィール│大井川かずひこ（大井川和彦）WEB SITE]</ref>。[[土浦市立真鍋小学校]]に入学後、父親の転勤のため、[[日立市立宮田小学校]]に転校した。日立市立宮田小学校、[[茨城大学教育学部附属中学校]]、[[茨城県立水戸第一高等学校・附属中学校|茨城県立水戸第一高等学校]]、[[東京大学大学院法学政治学研究科・法学部|東京大学法学部]]卒業<ref name="profile"/>。[[1988年]]、[[経済産業省|通商産業省]]（現[[経済産業省]]）入省<ref name="profile"/>。[[1996年]]、[[ワシントン大学 (ワシントン州)|ワシントン大学]][[ロー・スクール_(アメリカ合衆国)|ロースクール]]修了（国費留学）<ref name="profile"/>。[[1998年]]、通商産業省の初代[[シンガポール]]事務所長に就任<ref name="profile"/>。

[[2003年]]、経済産業省を退官し、同年より[[マイクロソフト|マイクロソフトアジア]]執行役員<ref name="profile"/>。マイクロソフト（現日本マイクロソフト）執行役常務を経て、[[2010年]]より[[シスコシステムズ]]（日本法人）専務執行役員<ref name="profile"/>。[[2016年]]、[[ニコニコ動画]]の運営会社である[[ドワンゴ]]の取締役に就任した<ref name="profile"/>。

=== 茨城県知事 ===
{{Seealso|2017年茨城県知事選挙}}
[[2016年]]12月、翌年に実施される[[2017年茨城県知事選挙|茨城県知事選挙]]への立候補に向け、[[自由民主党_(日本)|自由民主党]]茨城県連が大井川を擁立する方向で最終調整を進めていることが報道された<ref>{{Cite news|url = https://web.archive.org/web/20161204183205/http://www.sankei.com/politics/news/161204/plt1612040020-n1.html |title = 「ドワンゴ」取締役・大井川和彦氏、茨城知事選に擁立へ 自民県連が最終調整…元経産官僚の顔も |newspaper = [[産経新聞]] |date = 2016-12-04 |accessdate = 2018-09-17}}</ref>。[[2017年]][[3月1日]]、[[水戸市]]内で記者会見を開き、正式に茨城県知事選への立候補を表明した<ref>{{Cite news|url = https://www.sankei.com/article/20170302-WHPFH3O6GJJBXFIR3UPU2G4HB4/ |title = 茨城知事選、大井川氏が立候補表明 橋本氏出馬は「望むところ」 |newspaper = [[産経新聞]] |date = 2017-03-02 |accessdate = 2018-09-17}}</ref>。大井川の出馬検討が報じられた段階では、現職の[[橋本昌]]は自身の進退を明らかにしていなかったが、[[4月5日]]に橋本知事も出馬を表明<ref>{{Cite news|url = https://mainichi.jp/articles/20170405/k00/00e/010/297000c |title = 茨城知事選：橋本氏が7選目指し出馬表明 |newspaper = [[毎日新聞]] |date = 2017-04-05 |accessdate = 2018-09-17}}</ref>。[[7月19日]]、[[公明党]]からも推薦を受けたが<ref>{{Cite news|url = https://mainichi.jp/articles/20170719/ddl/k08/010/136000c |title = 茨城知事選'17：公明、大井川氏推薦 自民との連携を優先／茨城 |newspaper = [[毎日新聞]] |date = 2017-07-19 |accessdate = 2018-09-17|archiveurl=https://web.archive.org/web/20180917181910/https://mainichi.jp/articles/20170719/ddl/k08/010/136000c|archivedate=2018-09-17}}</ref>、対する橋本知事は茨城県市長会や茨城県町村会、[[日本労働組合総連合会|連合]]茨城、茨城県医師連盟、茨城県歯科医師連盟等から推薦を受けた<ref>{{Cite news|url = https://mainichi.jp/articles/20170810/k00/00e/010/245000c |title = 茨城知事選：選挙戦スタート 現新3氏が立候補 |newspaper = [[毎日新聞]] |date = 2017-08-10 |accessdate = 2018-09-17}}</ref><ref>{{Cite news|url = https://www.sankei.com/article/20170428-PCX2W52ZNFLIRLLWFXGLSLRCTI/ |title = 茨城知事選、橋本氏に推薦状続々 県町村会、県医師連盟など |newspaper = [[産経新聞]] |date = 2017-04-28 |accessdate = 2018-09-17}}</ref>。なお、連合茨城には大井川も推薦依頼を出していたが、連合茨城は大井川を推薦せず、橋本知事を推薦した<ref>{{Cite news|url = https://www.sankei.com/article/20170616-GFI3BYFKPJOQHDMIFTVIA5THDE/ |title = 連合茨城が橋本氏推薦 県政を評価 |newspaper = [[産経新聞]] |date = 2017-06-16 |accessdate = 2018-09-17}}</ref>。

告示日の[[8月10日]]、[[日本原子力発電]][[東海第二発電所]]の再稼働の是非について、明確な見解を示してこなかった橋本知事が「認めない方向にかじを切りたい」と表明<ref>{{Cite news|url = https://mainichi.jp/articles/20170815/k00/00m/010/116000c |title = 茨城知事選：現職の「再稼働NO」に波紋 |newspaper = [[毎日新聞]] |date = 2017-08-15 |accessdate = 2018-09-17}}</ref>。これに対し、大井川は「賛成でも反対でもない」というスタンスに終始し、再稼働の是非を明確に示さなかった<ref>{{Cite news
|url = http://www.tokyo-np.co.jp/article/ibaraki/list/201708/CK2017081702000182.html |title = 知事選 候補者アンケート（下） |newspaper = [[東京新聞]] |date = 2017-08-17 |accessdate=2017-09-13}}</ref>。公約では「新しい茨城」を掲げ、多選禁止条例の制定や18歳までの一部医療費の無料化、[[首都圏新都市鉄道つくばエクスプレス|つくばエクスプレス]]の県内区間の延伸検討等を主張した<ref name="ibaraki">{{Cite news|url = https://ibarakinews.jp/news/newsdetail.php?f_jun=15038318846602 |title = 知事に大井川氏 刷新訴え初当選 橋本氏の7選阻む |newspaper = [[茨城新聞]] |date = 2017-08-28 |accessdate = 2018-09-17}}</ref>。

[[8月27日]]に投開票が行われ、大井川が橋本知事ら2候補を破り、初当選した<ref>{{Cite news|url = https://www.sankei.com/article/20170827-B66EDYVEDJN67I2KSUM7FC4IGI/ |title = 【茨城県知事選】自公推薦新人の大井川和彦氏が初当選 現職の7選阻む |newspaper = [[産経新聞]] |date = 2017-06-16 |accessdate = 2018-09-17}}</ref>。茨城県知事選で、新人が現職の知事を破って当選するのは58年ぶり<ref name="ibaraki"/>。当選後の会見で、記者から「自民党の傀儡知事になるのではといわれたが」と質問されたのに対し、色をなして「何をもって傀儡というのか。今までの橋本県政もほとんど自民党が支持してやってきたが、橋本県政は傀儡だったのか」「非常に愚問だ」などと反論した<ref>{{Cite news|url = https://www.sankei.com/article/20170923-EOHG47AYQVNIXPOUY5SIKKYXJI/ |title = 【ニュースの深層】「自民傀儡」か「物言う知事」か 茨城・大井川和彦県政が26日スタート |newspaper = [[産経新聞]] |date = 2017-09-23 |accessdate = 2018-09-17}}</ref>。[[9月26日]]、茨城県庁に初登庁し、正式に茨城県知事に就任した。茨城県知事の交代は[[1993年]]の橋本知事の初当選以来、24年ぶり<ref>{{cite news|url = http://ibarakinews.jp/news/newsdetail.php?f_jun=15064191473038 |title = 大井川県政スタート 初登庁 「挑戦する茨城に」 |newspaper = [[茨城新聞]] |date = 2017-09-27 |accessdate = 2017-09-27}}</ref>。

2021年9月5日投開票の知事選で日本共産党推薦候補を破り再選。
{{Seealso|2021年茨城県知事選挙}}

2024年2月20日、茨城県は、大井川が転倒し頭部を打撲したことによる[[急性硬膜外血腫]]で同月17日に入院したと発表した。当面は[[テレワーク]]などで業務を行い、一部の公務は副知事が代理対応する<ref>{{Cite news|url=https://www.nikkei.com/article/DGXZQOCC198560Z10C24A2000000/|title=茨城県知事、頭部打撲による急性硬膜外血腫で入院|newspaper=日本経済新聞|date=2024-02-20|accessdate=2024-02-20}}</ref><ref>{{Cite news|url=https://ibarakinews.jp/news/newsdetail.php?f_jun=17084109659894|title=茨城県の大井川知事が入院・手術 転倒し頭部に血腫|newspaper=茨城新聞|date=2024-02-20|accessdate=2024-02-20}}</ref>。

2025年9月7日投開票の知事選で3選<ref>{{Cite web|date=2025年9月8日|title=茨城県知事選挙 現職の大井川和彦氏 3回目の当選|publisher=日本放送協会|url=https://www3.nhk.or.jp/news/html/20250907/k10014909191000.html|access-date=2025年9月8日}}</ref>。

== 県政 ==
* [[2018年]][[4月]]より県庁の決裁事務の電子決裁化を指示し、同7月には99.1%の電子決裁化を達成した<ref>{{Cite news| author=重政紀元 |url = https://digital.asahi.com/articles/ASL8Z6T48L8ZUJHB00D.html |title = ハンコよさらば！ 茨城県庁の決裁、ほぼ100％電子化 |newspaper = [[朝日新聞]] |date = 2018-09-24 |accessdate = 2019-06-24}}</ref>。
* [[2019年]][[6月24日]]、[[LGBT]]など[[性的少数者]]のカップルが婚姻に相当する関係にあると認める「パートナーシップ宣誓制度」を7月1日から導入すると発表した。都道府県ベースでは全国初となる<ref>{{Cite news|url = https://digital.asahi.com/articles/ASM6S3DFSM6SUJHB006.html |title = 茨城県でパートナーシップ制度 自民反対も知事が独断 |newspaper = [[朝日新聞]] |date = 2019-06-24 |accessdate = 2019-06-24}}</ref>。制度導入に反対を示してきた[[茨城県議会]]の最大会派「いばらき自民」<ref>{{Cite news|url = https://www.sankei.com/life/news/190325/lif1903250028-n1.html |title = 茨城県がLGBT差別禁止を明文化　東京に次いで2例目 |newspaper = [[産経新聞]] |date = 2019-03-25 |accessdate = 2019-03-25|archiveurl=https://web.archive.org/web/20190325085923/https://www.sankei.com/life/news/190325/lif1903250028-n1.html|archivedate=2019-03-25}}</ref>からは「残念だ」との声が上がった<ref>{{Cite news| author=鈴木学 |url = https://web.archive.org/web/20190625014951/https://www.tokyo-np.co.jp/article/ibaraki/list/201906/CK2019062502000166.html |title = 県議会自民「残念」「注視」 県パートナーシップ制度 |newspaper = [[東京新聞]] |date = 2019-06-24 |accessdate = 2019-06-25}}</ref>。
* 当選時は東海第二原発の再稼働については「有権者の判断に委ねる」として中立の立場であり、[[2019年]][[2月]]に[[日本原電]]の経営陣と対談した際にも県の安全審査で結論が出る前から再稼働ありきで話を進める原電側の姿勢には不快感を表明していた<ref>{{Cite news|url = https://www.nikkei.com/article/DGXMZO41600470S9A220C1000000/ |title = 原電、東海第2再稼働を表明 茨城知事は不快感 |newspaper = [[日本経済新聞]] |date = 2019-02-22 |accessdate = 2021-05-12}}</ref>。一方で、[[東海村]]の[[山田修 (政治家)|山田修]]村長が[[2019年]][[10月]]、原子力専門の雑誌「エナジー・フォー・ザ・フューチャー」における[[新潟県]][[刈羽村]]の[[品田宏夫]]村長との対談で、[[東海第二発電所]]の再稼働容認や反原発論者に対する「全ての外部電源を遮断して、自家発電だけで生活してもらわなくては。自宅から一歩も出てはいけない」などといった発言<ref>{{Cite news|url = https://www.asahi.com/articles/ASMCH6Q4YMCHUJHB00J.html |title = 原発不要なら「自宅から出るな」 東海村長、雑誌対談で |newspaper = [[朝日新聞]] |date = 2019-11-16 |accessdate = 2021-05-12|archiveurl=https://web.archive.org/web/20191116180903/https://www.asahi.com/articles/ASMCH6Q4YMCHUJHB00J.html|archivedate=2019-11-16}}</ref>をしたことに対しては「一般論だと認識している」と述べるに留まった<ref>{{Cite news|url = https://web.archive.org/web/20210512150400/https://www.tokyo-np.co.jp/article/10914 |title = 東海村村長発言、知事「一般論と認識」 |newspaper = [[東京新聞]] |date = 2019-11-13 |accessdate = 2021-05-12}}</ref>。
* [[2021年]][[5月12日]]の記者会見で、[[東京オリンピック・パラリンピック競技大会組織委員会]]から、[[2020年東京オリンピック・パラリンピック|東京五輪]]出場選手や関係者が[[新型コロナウイルス感染症の世界的流行_(2019年-)|新型コロナウイルス]]に感染した際に受け入れる専用病床の確保を求められたが、「（茨城）県民より選手を優先できない」として要請を拒否したことを明らかにした。あわせて、東京五輪開催の是非については「必ずやらなければいけないことではない。状況に応じて中止の判断もあり得る」「大阪府が陥っているような医療崩壊に近い状況で五輪だけを開催するならば、国内だけでなく世界から理解を得られない」との見解を示した<ref>{{Cite news|url = https://web.archive.org/web/20210512044102/https://this.kiji.is/765070003032244224?c=39546741839462401 |title = 五輪選手の病床確保の要請を拒否 茨城知事、五輪組織委に |newspaper = [[共同通信]] |date = 2021-05-12 |accessdate = 2021-05-12}}</ref>。
