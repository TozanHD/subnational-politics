'''中村 時広'''（なかむら ときひろ、[[1960年]]〈[[昭和]]35年〉[[1月25日]]<ref>『全国歴代知事・市長総覧』日外アソシエーツ、2022年、370頁。</ref> - ）は、[[日本]]の[[政治家]]。[[愛媛県知事]]（公選第17・18・19・20代）。[[無所属]]<ref>{{Cite web|title=総務省｜地方公共団体の議会の議員及び長の所属党派別人員調等|url=https://www.soumu.go.jp/senkyo/senkyo_s/data/syozoku/index.html|website=総務省|access-date=2025-09-10|language=ja}}</ref>。

[[松山市|松山市長]]（第27・28・29代）、[[衆議院|衆議院議員]]（1期）、[[愛媛県議会|愛媛県議会議員]]（1期）を歴任。元松山市長の[[中村時雄]]は父。

== 来歴 ==
[[愛媛県]][[松山市]]生まれ<ref>{{Cite web|title=知事のあいさつ - ようこそ知事室へ - 愛媛県庁公式ホームページ|url=https://www.pref.ehime.jp/site/chiji/10563.html|website=www.pref.ehime.jp|access-date=2025-09-10}}</ref>。[[慶應義塾幼稚舎]]、[[慶應義塾普通部]]、[[慶應義塾高等学校]]、[[慶應義塾大学大学院法学研究科・法学部|慶應義塾大学法学部]][[法学部|法律学科]]卒業。[[1982年]]、[[三菱商事]]に入社し、燃料部に配属される<ref>[http://www.tokihiro.jp/prof.html 愛媛県知事 - 中村時広 オフィシャルウェブサイト|TOKIHIRO.JP - プロフィール]</ref>。

[[1987年]]に[[愛媛県議会|愛媛県議会議員]]選挙で立候補し、初当選した。[[1990年]]に1期目の任期途中で愛媛県議を辞職し、[[第39回衆議院議員総選挙]]に[[愛媛県第1区_(中選挙区)|旧愛媛1区]]（定数3）から[[無所属]]で立候補したが、得票数5位で落選した。のちに[[日本新党]]に参加して[[1993年]]の[[第40回衆議院議員総選挙]]で日本新党公認で旧愛媛1区から立候補する。[[日本社会党]]前職の[[宇都宮真由美]]に約7千票差で勝ち、得票数3位で当選した。[[1994年]]に日本新党が解党して[[新進党]]へ合流する。[[1996年]]の[[第41回衆議院議員総選挙]]で、新進党公認で[[愛媛県第1区|愛媛1区]]から立候補したが、[[自由民主党_(日本)|自由民主党]]前職の[[関谷勝嗣]]に約5千票差で敗れ、落選した。

=== 松山市長 ===
==== 1999年松山市長選 ====
{{main|1999年松山市長選挙}}
保守地盤が厚い愛媛から国政に復帰することは困難とみられていたが、市民グループや一部市議から松山市長に推す声が高まり、[[1999年]]の松山市長選挙に立候補する。3選を目指す現職の[[田中誠一]]は自民党・[[社会民主党 (日本 1996-)|社民党]]・[[民主党 (日本 1998-2016)|民主党]]・[[民社協会]]の各支部から支持や推薦を取り付け、[[オール与党]]体制で選挙戦を展開した。田中はかつて助役として仕えた市長の中村時雄に反旗を翻して落選に至らせ、親子二代にわたる因縁の対決とする見方もあった。

中村は単なる新人ではなく、父親が松山市長で自らも元国会議員と政治的な資産があり、「[[草の根民主主義|草の根]]保守」が強く個別の人間関係の影響が大きい愛媛の選挙戦で有利に働いた。[[愛媛県知事]]に就任したばかりの[[加戸守行]]が「一市民として」中村の支持を表明したことは、県政と市政の繋がりを重視する層や政治的関心の薄い層の間に中村の支持を広げ、県知事選の余韻が残っていたことも中村に追い風となった。田中は組織戦重視の選挙戦を展開し、町内会レベルまで支持と推薦を求め、2月の段階で800もの組織から支援を受けていた。松山は都市化の進行で組織票が弱いことから、中村が現職の田中を下して松山市長に就任した<ref>[[河村和徳]]『現代日本の地方選挙と住民意識』（[[慶応義塾大学]]出版社、[[2008年]]）153 - 173ページ</ref><ref>[[市川虎彦]]『保守優位県の都市政治』（[[晃洋書房]]、[[2011年]]）21 - 23ページ</ref>。

==== 中村市政 ====
中村は39歳と歴代の松山市長と比べてかなり若かった<ref>前掲市川23ページ</ref>。当時は[[今治市]]の[[越智忍]]、[[西条市]]の[[伊藤宏太郎]]、[[四国中央市]]の[[井原巧]]と、松山以東の市町村は中村以外にも世襲の市長が多かった<ref>前掲市川74ページ</ref>。中村はオール与党体制を構築し、市長選は連続当選で3期11年間市長を務める。

中村は[[司馬遼太郎]]の小説『[[坂の上の雲]]』をモチーフに「坂の上の雲のまちづくり」を展開し、30億円かけて[[2007年]]に[[坂の上の雲ミュージアム]]を開設するも、市長主導の政策で市民の多くは無関心だったが、[[日本放送協会|NHK]]が[[坂の上の雲 (テレビドラマ)|ドラマ化]]したことで市民の間に認知が進んだとされる<ref>前掲市川24ページ</ref>。しかし、この観光振興による地域活性化は上手くいかず、松山経済の地盤沈下は進展したと評される<ref>前掲市川29 - 30ページ</ref>。

[[松山中央公園野球場|坊っちゃんスタジアム]]への[[オールスターゲーム_(日本プロ野球)|オールスターゲーム]]誘致や、[[フィールド・ミュージアム]]の考えを取り入れた。松山市役所の行政改革に取り組み、[[2000年]]に[[四国]]で初めて総合窓口を導入し、[[2006年]]にコールセンターを開設した。中村の市長在任中、松山市は四国内で1位かつ唯一の50万都市だったが、周辺に大きな都市がなく合併を重ねても人口規模拡大は現実的に困難であるため、積極拡大政策により[[政令指定都市]]を目指したり[[道州制]]導入後の[[州都]]を目指す考えは示さなかった。

[[2009年]]8月に[[大阪府知事]]（当時）の[[橋下徹]]らとともに、「首長連合」として[[第45回衆議院議員総選挙]]で[[民主党 (日本 1998-2016)|民主党]]を支持すると表明した<ref>{{cite news|url = https://web.archive.org/web/20090814133338/http://www.yomiuri.co.jp/election/shugiin2009/news1/20090811-OYT1T00878.htm|title = 「首長連合」は民主支持…橋下府知事ら発表|accessdate = 2016-06-19}}</ref>。同年[[10月30日]]、[[鳩山由紀夫内閣]]下で[[総務省]]顧問に就任<ref>{{Cite web |title=asahi.com（朝日新聞社）：橋下知事・河村市長ら総務省顧問に　「地域主権」担当 - ２００９政権交代 |url=https://www.asahi.com/seikenkotai2009/TKY200910300122.html |website=www.asahi.com |access-date=2023-12-13}}</ref>。

=== 愛媛県知事 ===
[[2010年]]9月、愛媛県知事の加戸が任期を2ヶ月残して辞任した。それに伴う県知事選挙への立候補を表明し、10月21日に松山市議会議長に辞職願を提出した<ref>{{cite news|url = http://mytown.asahi.com/ehime/news.php?k_id=39000331010220002|title = 中村市長が退職願|newspaper = [[朝日新聞]]|date = 2010-10-22|accessdate = 2010-10-26}}</ref>。松山市議会の会派である[[松山維新の会]]からも推薦を受けた<ref>{{cite news|url = http://mytown.asahi.com/ehime/news.php?k_id=39000331010140001 |title = 松山維新の会 中村氏を推薦|newspaper = [[朝日新聞]]|date = 2010-10-14|accessdate = 2011-07-13}}</ref>。県知事選は加戸前知事の事実上の後継候補選挙で、自民党をはじめ県議会に議席を有する各政党から支援を受けた一方で、中村の辞職に伴う松山市長選挙で自民党愛媛県連が候補を擁立したが、中村は自身の後継候補である[[野志克仁]]を支援した<ref>{{cite news|url = http://mainichi.jp/area/ehime/archive/news/2010/10/03/20101003ddlk38010329000c.html|title = 松山市長選　自民、事実上分裂へ　一本化失敗|newspaper = [[毎日新聞]]|date = 2010-10-03|accessdate = 2010-10-26}}</ref>。11月28日投開票の愛媛県知事・松山市長のダブル選挙で、知事選は中村が、市長選は中村が擁立した野志が当選した<ref>{{cite news|url = https://web.archive.org/web/20101203133937/http://sankei.jp.msn.com/politics/election/101128/elc1011282126003-n1.htm |title = 愛媛県知事選 与野党相乗りの中村氏 初当選確実|newspaper = [[産経新聞]]|date = 2010-11-28|accessdate = 2010-11-28}}</ref>。これにより中村は愛媛県政と松山市政を一気に掌握した<ref>前掲市川29ページ</ref>。

[[2012年]]9月2日、自身が代表を務める政治塾「えひめ志高塾」を開講した。[[2014年]]11月の県知事選挙で、自由民主党・[[民主党 (日本 1998-2016)|民主党]]の県連の推薦、[[みんなの党]]・[[社会民主党_(日本 1996-)|社会民主党]]の地方組織の支援を受け、県知事に再選された<ref>{{cite news|url = https://web.archive.org/web/20141119015906/http://www.yomiuri.co.jp/election/local/20141116-OYT1T50047.html|title = 愛媛知事選、現職の中村時広氏が再選|newspaper = [[読売新聞]]|date = 2014-11-16|accessdate = 2015-02-28}}</ref>。2018年の県知事選挙では自民党や[[立憲民主党 (日本 2017)|立憲民主党]]、[[国民民主党 (日本 2018)|国民民主党]]、公明、社民の県組織の推薦や支援を受け、新人2候補を破り3選を果たした<ref>{{Cite web|title=愛媛県知事選、中村時広氏が３選 新顔２人を破る：朝日新聞|url=https://www.asahi.com/articles/ASLCJ45T2LCJPFIB00P.html?iref=ogimage_rek|website=朝日新聞|date=2018-11-18|access-date=2025-09-10|language=ja}}</ref>。

2012年4月に県産品や県内企業の技術売り込みを行う組織として知事直属の「愛のくにえひめ営業推進本部」を設置。平成29年度には商談会･フェア等の開催件数が684件、参加企業が延べ5,140社、ビジネスマッチングなどで4,418件、約113億円の成約実績を上げている<ref>[https://www.pref.ehime.jp/h01999/teirei/documents/01_h29_jigyoujisseki_sokuhouchi.pdf 平成29年度営業活動に係る事業実施実績等について(pdf)]</ref>。

2022年11月20日執行の[[2022年愛媛県知事選挙|知事選挙]]では得票率90.3％の圧勝で4選を果たした<ref>{{Cite news|url=https://web.archive.org/web/20221120110237/https://www3.nhk.or.jp/news/html/20221120/k10013897831000.html|title=愛媛県知事選 現職の中村時広氏 4回目の当選|work=NHK NEWSWEB|agency=[[日本放送協会|NHK]]|date=2022-11-21|accessdate=2022-11-21}}</ref>。

== 人物 ==
* 趣味は読書、スキー、[[バドミントン]]。
* 自転車文化の普及に熱心であり、「石鎚ヒルクライム」や「[[しまなみ海道サイクリングロード|しまなみサイクリング]]」のイベント開催に尽力した。[[2013年]]のしまなみサイクリングに自身も参加し、最遠距離設定の110キロメートルコースを完走した。
* 「既存のものを壊すのが大好き」とされている。「同タイプ」の橋下徹から慕われており、中村が彼に「府県と県庁所在地の首長を同時に掌握するメリットなどを教えた」と報道されたこともある<ref>{{cite news|url = https://dot.asahi.com/articles/-/9082|title = ある大物知事　橋下氏と小沢氏の橋渡しで永田町入り？|accessdate = 2016-06-19}}</ref>。
* 筋金入りのプロレスファンでもある。2019年6月2日、[[DDTプロレスリング]]の[[アイテムえひめ]]大会において行われた[[アイアンマンヘビーメタル級王座]]選手権試合の勝利者賞目録授与のためにリングに上がったところ、王者・[[大石真翔]]が他の選手に襲撃されダウン。そこを片エビ固めで押さえこみ3カウントフォールが成立、第1368代王者となる<ref>[[アイアンマンヘビーメタル級王座]]は試合が組まれていなくても王者に勝利したと看做されれば王座が移動する。</ref>。しかし直後に[[男色ディーノ]]に襲撃されギブアップを宣言、約1分で王座陥落<ref>{{cite news|url = https://www.tokyo-sports.co.jp/articles/-/142251|title = 【ＤＤＴ】現職の愛媛県知事がまさかのアイアンマンヘビーメタル級王座奪取|publisher=東スポWeb|accessdate = 2019-06-03}}</ref><ref>{{cite web|url = https://www.ddtpro.com/results/3057|title = WRESTLE MATSUYAMANIA 2019|publisher=DDTプロレスリング|accessdate = 2019-06-03}}</ref>。
