'''福田 富一'''（ふくだ とみかず、[[1953年]]〈[[昭和]]28年〉[[5月21日]]<ref>『全国歴代知事・市長総覧』日外アソシエーツ、2022年、82頁。</ref> - ）は、[[日本]]の[[政治家]]。[[栃木県知事一覧|栃木県知事]]（公選第16・17・18・19・20・21代）。[[無所属]]<ref>[https://www.soumu.go.jp/senkyo/senkyo_s/data/syozoku/index.html 総務省 地方公共団体の議会の議員及び長の所属党派別人員調等]</ref>。[[自由民主党 (日本)|自由民主党]]栃木県連顧問<ref>{{Cite web |title=とちぎ自民党　県連組織・役員紹介 |url=http://www.tochigi-jimin.com/soshiki.html |website=www.tochigi-jimin.com |access-date=2025-07-18}}</ref>。

[[宇都宮市#歴代首長|宇都宮市長]]（2期）、[[栃木県議会|栃木県議会議員]]（2期）、[[宇都宮市議会|宇都宮市議会議員]]（2期）を務めた。

== 経歴 ==
[[1953年]][[5月21日]]、[[栃木県]][[上都賀郡]]今市町（後の[[今市市]]／現・[[日光市]]）で生まれる。[[1972年]]3月、[[栃木県立宇都宮工業高等学校]]を卒業。同年4月、[[栃木県庁]]に入庁。[[1979年]]3月、[[日本大学理工学部・大学院理工学研究科|日本大学理工学部]][[建築学科]]を卒業。[[1981年]]4月、栃木県庁を退職し、建築設計・[[行政書士]]事務所を開業。

[[1983年]]5月、[[宇都宮市議会|宇都宮市議会議員]]選挙に出馬し、初当選（〜[[1990年]]2月）。[[1991年]]4月、[[宇都宮市]]選挙区から[[栃木県議会|栃木県議会議員]]選挙に出馬し、当選（〜[[1999年]]3月）。

1999年4月、[[宇都宮市#歴代首長|宇都宮市長]]選挙に出馬し、当選（〜[[2004年]]10月）。

2004年12月、[[栃木県知事一覧|栃木県知事]]選挙に出馬し、現職の[[福田昭夫]]を破り、初当選。

[[2008年]]11月、栃木県知事選挙で2選。

[[2012年]]11月、[[2012年栃木県知事選挙|栃木県知事選挙]]で3選。

[[2016年]]11月、[[2016年栃木県知事選挙|栃木県知事選挙]]で4選。

[[2020年]]11月、[[2020年栃木県知事選挙|栃木県知事選挙]]で5選。

[[2024年]]11月、[[2024年栃木県知事選挙|栃木県知事選挙]]で6選。

== 人物 ==
宇都宮市長在職中は[[宇都宮二荒山神社]]周辺の[[市街地再開発]]を推進した<ref>{{Cite web|和書|url=http://www.tokeikyou.or.jp/machidukuri/title.php?year=2003&month=5 |title=月刊まちづくり情報 |publisher=都市計画協会 |date=2003-05 |accessdate=2012-05-28 }}</ref>。また、後に[[宇都宮ライトレール]]として整備される[[新交通システム]]の推進や、周辺市町との合併による[[政令指定都市]]への移行を目指していた<ref>「宇都宮市長所信表明 政令指定都市も視野 新交通システム具体化へ」-『下野新聞』[[2003年]][[6月11日]]朝刊6面</ref>。

[[ファイル:Kanseki stadium tochigi inside.jpg|thumb|カンセキスタジアムとちぎ]]
栃木県知事に就任後、2007年9月、[[宇都宮競馬場]]跡地に陸上競技場、サッカー場兼用スタジアム（後の[[カンセキスタジアムとちぎ]]）を新設する計画を発表した<ref>読売新聞 2007年9月11日</ref><ref>朝日新聞 2007年9月12日</ref>。[[2008年]]の知事選の[[公約]]に「高等特別支援学校の整備（軽度障害児の自立支援）」を掲げ<ref>"「人づくり」「安心」掲げる 福田氏、知事再選へ公約"[[朝日新聞]]2008年10月9日付朝刊、栃木版31ページ</ref>、[[栃木県立特別支援学校宇都宮青葉高等学園]]の開校（2016年）に結び付けた<ref>高田結奈「企業と連携 手厚い職業教育 特別支援学校 宇都宮青葉高等学園 地域の事業所で就業体験」[[読売新聞]]2019年2月4日付朝刊、栃木版26ページ</ref>。

2012年5月25日、同年11月の栃木県知事選に3選を目指して出馬する意向を表明。その後[[みんなの党]]の[[渡辺喜美]]代表から、県内の[[除染]]など、[[福島第一原子力発電所事故]]の対策が遅いと批判されたことに対して、5月27日に自民党の[[政治資金パーティー]]で[[環境省]]の同意がないと先に進まないことをあげて反論した<ref name="shimotuke1">{{Cite news|url = http://www.shimotsuke.co.jp/news/tochigi/top/news/20120527/793032|title = 福田知事、渡辺氏の批判に反論 自民にはエール、蜜月演出|newspaper = [[下野新聞]]|date = 2012-05-28|accessdate = 2012-05-28}}</ref>。なお、知事選には自民党の党籍を持ったまま無所属で立候補する意向を示した<ref name="shimotuke2">{{cite news|url = http://www.shimotsuke.co.jp/journal/politics/election/news/20120525/791627|title = 福田知事3選出馬表明 公約骨子人材育成など7項目|newspaper = 下野新聞|date = 2012-05-26|accessdate = 2012-10-28}}</ref>。

2017年6月2日の記事では「取材班は社会保障制度の維持には医療費の適正化や抑制が必要だと考えています。都道府県は何ができて、何ができないのでしょうか」という記者の問いに対して　「社会保障は持続可能性を高めながら、必要な医療介護を受けられる体制を整備していかなければならない。住民が住み慣れた地域で必要な医療介護を受けたうえで、医療費の適正化や地域差の縮小が図られるべきだ。一方的に財政緊縮の役割を都道府県に負わせるのは筋が違う」「都道府県がすぐに取り組めるのは住民の健康づくり。病気にならないように生涯現役を築き、おのずと健康づくりや医療費の抑制につながっていく社会を目指すべきだ。市町村の健康増進事業、特定健康診査の実施率の向上などに支援や助言をしているが、県の役割は限定的ではないか」と話している<ref>[https://www.nikkei.com/article/DGXMZO17126950R30C17A5I00000/ 福田富一・栃木県知事「医療費抑制、県の役割は限定的」 それぞれの責任（５）] 2017/6/2 2:00日本経済新聞　電子版</ref>。

2020年秋の「都道府県魅力度ランキング」で栃木県が初の47位に転落したことを受け、10月19日、調査会社の[[ブランド総合研究所]]に出向き、調査方法などに関する提案書を提出し直談判することを明らかにした<ref>{{Cite web|和書|url=https://www.shimotsuke.co.jp/articles/-/374080 |title=調査会社に「直談判」へ　“魅力度最下位”で栃木県知事 |date=2020-10-19 |accessdate=2020-10-20 |publisher=下野新聞「SOON」ニュース}}</ref>。

[[2023年徳島県知事選挙|2023年の徳島県知事選挙]]で[[飯泉嘉門]]が落選して以来、現職では最古参の知事となっている。

=== 統一教会との関係 ===
[[旧統一教会問題]]に関して[[共同通信社]]が行ったアンケートに対し、[[世界平和統一家庭連合]]（旧統一教会）の関連団体が開催した「国難突破 日本とアジアの未来を拓く栃木大会（2022年5月22日）」に祝電を送ったと回答。「県議が代表だったので十分に確認せず祝電対応した」としている<ref>{{Cite web |title=福田富一 |url=https://digital.kyodonews.jp/static/ucl/tochigi/member/0.html |website=digital.kyodonews.jp |access-date=2024-07-01}}</ref>。
