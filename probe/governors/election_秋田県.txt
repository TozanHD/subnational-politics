'''2025年秋田県知事選挙'''（2025ねんあきたけんちじせんきょ）は、[[秋田県]]における[[執行機関]]の一つである[[秋田県知事一覧|秋田県知事]]を選出するために[[2025年]][[4月6日]]に行われた[[選挙]]である。

==概要==
4期目現職の[[佐竹敬久]]は前回知事選後に立候補しない意向を示し、新人同士の選挙戦となった<ref>[https://www.yomiuri.co.jp/election/20230418-OYT1T50072/ 佐竹知事、２年後の知事選出馬「１万％ない」…後継指名せず「専制君主でない」]讀賣新聞　2023年4月18日</ref>。

元[[自由民主党 (日本)|自由民主党]]所属で前秋田県議会議員の[[鈴木健太 (政治家)|鈴木健太]]、元秋田県副知事の[[猿田和三]]、元会社員の大久保範夫が立候補し、事実上鈴木と猿田の一騎打ちとなった<ref>{{Cite web |title=来年４月の知事選 猿田和三氏が立候補表明｜NHK 秋田県のニュース |url=https://www3.nhk.or.jp/lnews/akita/20241125/6010022905.html |website=NHK NEWS WEB |access-date=2025-04-06 |last=日本放送協会|archiveurl=https://web.archive.org/web/20250114224713/https://www3.nhk.or.jp/lnews/akita/20241125/6010022905.html|archivedate=2025-01-14}}</ref><ref>{{Cite web |title=来年４月の秋田県知事選 鈴木健太氏が立候補表明｜NHK 秋田県のニュース |url=https://www3.nhk.or.jp/lnews/akita/20241115/6010022830.html |website=NHK NEWS WEB |access-date=2025-04-06 |last=日本放送協会|archiveurl=https://web.archive.org/web/20250805042514/https://www3.nhk.or.jp/lnews/akita/20241115/6010022830.html|archivedate=2025-08-05}}</ref>。

鈴木の当選によって第3代～第8代と6期連続で知事を務めた'''[[小畑勇二郎]]（初当選時48歳）以来70年ぶりに初当選時40代の知事が誕生'''した。初当選時40代の秋田県知事は公選制初代の[[蓮池公咲]]と小畑に次いで3人目。'''県外出身者の知事は初代の蓮池が退任して以来74年ぶり'''になる。

== 政党の対応 ==
* [[自由民主党 (日本)|自由民主党]]秋田県連は猿田・鈴木の双方から推薦依頼を受けたが、2025年1月に「保守系の方で、どちらもふさわしい」（[[御法川信英]]会長）として自主投票を決定。党所属の県議会議員は猿田の支援・鈴木の支援で割れ、事実上の[[分裂選挙|保守分裂選挙]]となった<ref>[https://www.yomiuri.co.jp/election/20250220-OYT1T50197/　佐竹知事不出馬で１６年ぶり新人対決見込みの秋田県知事選、保守分裂の様相…「一本化すれば県連が瓦解」]讀賣新聞　2025年2月25日</ref><ref>{{Cite web |title=秋田県知事選、相乗り候補敗れる 与野党「既成政党批判」と危機感 |url=https://mainichi.jp/articles/20250406/k00/00m/010/173000c |website=毎日新聞 |access-date=2025-04-06 |language=ja|archiveurl=https://web.archive.org/web/20250406143023/https://mainichi.jp/articles/20250406/k00/00m/010/173000c|archivedate=2025-04-06}}</ref><ref>{{Cite web |title=佐竹知事不出馬で１６年ぶり新人対決見込みの秋田県知事選、保守分裂の様相…「一本化すれば県連が瓦解」 |url=https://www.yomiuri.co.jp/election/20250220-OYT1T50197/ |website=読売新聞オンライン |date=2025-02-25 |access-date=2025-04-06 |language=ja}}</ref><ref>{{Cite web |title=秋田知事に鈴木氏初当選 保守分裂、元副知事ら破る：時事ドットコム |url=https://www.jiji.com/jc/article?k=2025040600366&g=pol |website=時事ドットコム |date=2025-04-07 |access-date=2025-04-06 |language=ja |first=時事通信 |last=内政部|archiveurl=https://web.archive.org/web/20250407005600/https://www.jiji.com/jc/article?k=2025040600366&g=pol|archivedate=2025-04-07}}</ref>。
* [[公明党]]・[[立憲民主党 (日本 2020)|立憲民主党]]・[[国民民主党 (日本 2020)|国民民主党]]・[[社会民主党 (日本 1996-)|社会民主党]]の県組織は猿田を支持。
* [[日本共産党]]は2013年の知事選以来12年ぶりに独自候補擁立を見送り、猿田を支持。
* [[日本維新の会 (2016-)|日本維新の会]]県総支部は鈴木を支援。
* [[参政党]]はいずれの候補者も支援せず自主投票とした。

== 開票結果 ==
鈴木が2候補を下し初当選した。鈴木と猿田の接戦といわれたが、猿田は全25市町村中2つで鈴木の得票を上回ったのみで、23市町村を鈴木が抑え勝利した。
