'''木村 敬'''（きむら たかし、[[1974年]]〈[[昭和]]49年〉[[5月21日]]<ref>{{Cite web |和書 |title=熊本県知事選挙 {{!}} 選挙 |url=https://www.jimin.jp/election/207433.html |website=自由民主党 |access-date=2024-03-24 |language=ja}}{{リンク切れ|date=2024年8月}}</ref><ref>{{Cite web |和書 |title=プロフィール - 熊本県ホームページ |url=https://www.pref.kumamoto.jp/soshiki/1/203084.html |website=www.pref.kumamoto.jp |access-date=2024-04-21}}</ref> - ）は、[[日本]]の[[政治家]]、[[自治省|自治]]・[[総務省|総務]][[官僚]]。[[熊本県知事一覧|熊本県知事]]（公選第21代）。[[無所属]]<ref>[https://www.soumu.go.jp/senkyo/senkyo_s/data/syozoku/index.html 総務省 地方公共団体の議会の議員及び長の所属党派別人員調等]</ref>。[[熊本県]][[副知事 (日本)|副知事]]などを務めた。

== 来歴 ==
[[東京都]][[渋谷区]]出身<ref name="プロフィール">{{Cite web |和書 |url=https://kimura-takashi.jp/|title=プロフィール|accessdate=2024-03-25|website=きむら敬オフィシャルサイト}}</ref>。母の胎内で[[臍帯|へその緒]]が絡まったことで左手首から先を失い、障害を持って生まれた<ref name="プロフィール"/>。[[1981年]]、小学校に入学<ref name="プロフィール"/>。小学生の頃は家族旅行の際の温泉めぐりとご当地牛乳キャップを集めることが趣味であった<ref name="プロフィール"/>。その後、[[1987年]]に[[武蔵高等学校中学校|武蔵中学高等学校]]に入学<ref name="プロフィール"/>。浪人生活を経て[[1994年]]、[[東京大学]]に入学<ref name="プロフィール"/>。大学3年時に、のちに[[熊本県知事一覧|熊本県知事]]となる[[蒲島郁夫]]が[[筑波大学]]から東京大学に教授として赴任<ref name="プロフィール"/>。木村は蒲島ゼミに所属し、第1期ゼミ長を務めた<ref name="プロフィール"/>。また、[[国家公務員試験]]に落ちた後もゼミでの活動を続け、研究本を出版<ref name="プロフィール"/>。蒲島から研究者の道に誘われたが、[[自治省]]から内定をもらったことを理由に固辞した<ref name="プロフィール"/>。[[1999年]]3月、同大学法学部を卒業<ref name="選挙ドットコムプロフィール">{{Cite web |和書 |url=https://go2senkyo.com/seijika/193169#profile|title=木村敬　プロフィール・略歴|accessdate=2024-03-25|website=[[選挙ドットコム]]|publisher=イチニ}}</ref>。同年4月、[[自治省]]に入省<ref name="選挙ドットコムプロフィール"/>。入省後は[[岡山県庁|岡山県]]に赴任し、[[岡山県]]内にある日本酒蔵の紹介で[[高等学校教員|高校教諭]]の女性と知り合い、3年後に結婚<ref name="プロフィール"/>。

[[2004年]]、[[鳥取県庁|鳥取県]]に赴任し<ref name="プロフィール"/>、財政課長などを務めた<ref>{{Cite web |和書 |url=https://www.sanin-chuo.co.jp/articles/-/510635|title=熊本知事選に前副知事出馬へ　元鳥取県財政課長|date=2024-01-10|accessdate=2024-03-25|work=[[山陰中央新報]]|publisher=山陰中央新報社}}</ref>。赴任中に[[漫画家]]・[[水木しげる]]の薫陶を受けて、[[漫画]]を生かした地域づくりや[[郵便局]]を活用した中山間地活性化などの施策を提案し、遂行した<ref name="プロフィール"/>。

[[2012年]]7月、蒲島の誘いで[[熊本県庁|熊本県]]に赴任し<ref name="プロフィール"/>、商工政策課長、総務部政策審議監、総務部長を歴任<ref name="選挙ドットコムプロフィール"/><ref name="熊本日日200919">{{Cite web |和書 |url=https://kumanichi.com/articles/2790|title=蒲島熊本県知事、副知事に木村氏起用へ　消防庁広域応援室長|date=2020-09-19|accessdate=2024-03-25|work=[[熊本日日新聞]]|publisher=熊本日日新聞社}}</ref>。赴任中に住んでいた公舎で[[熊本地震 (2016年)|熊本地震]]に遭遇<ref name="プロフィール"/><ref name="人吉201010">{{Cite web |和書 |url=https://hitoyoshi-sharepla.com/news.php?news=3946|title=副知事に木村氏就任　本社訪れ抱負語る|date=2020-10-10|accessdate=2024-03-25|work=[[日刊人吉新聞]]|publisher=人吉新聞社}}</ref>。木村は蒲島とともに初動対応や被災者支援にあたり<ref name="プロフィール"/><ref name="朝日160829">{{Cite web |和書 |url=https://www.asahi.com/sp/articles/ASJ8V0BG7J8TUTIL02Z.html|title=「セブン」なぜ急増？　熊本地震、検索から見えたニーズ|date=2016-08-29|accessdate=2024-03-25|work=[[朝日新聞デジタル]]|publisher=[[朝日新聞社]]}}</ref>、任期が切れた後も政府現地対策本部員として被災地の支援にあたった<ref name="プロフィール"/>。[[2016年]]5月、[[総務省]][[自治財政局]]公営企業課理事官に就任<ref name="朝日160829"/>。同年6月から総務省に復帰し、復旧復興支援策の策定に取り組んだ<ref name="プロフィール"/>。その後は、[[内閣府]][[地方創生推進事務局]]企画官、[[消防庁]]防災課広域応援室長を歴任<ref name="選挙ドットコムプロフィール"/>。[[令和2年7月豪雨]]に際しては、[[緊急消防援助隊]]の総指揮を担当した<ref name="プロフィール"/>。[[2020年]]、木村を「蒲島ゼミ」の同期生でもある[[小野泰輔]]の後任の副知事とする人事案が[[熊本県議会]]に提出されることとなり<ref name="熊本日日200919"/>、同年[[10月9日]]、熊本県副知事に就任<ref name="人吉201010"/>。

== 不祥事・批判を受けた言動 ==
* 2024年5月1日、[[2024年熊本県知事選挙|同じ年の熊本県知事選挙]]直後に[[コチョウラン]]の鉢植えを熊本市の複数の知人や医療・福祉施設に渡していたことが分かった。[[公職選挙法]]は政治家に選挙区内での金品や物品の寄付を禁じている。木村は報道陣の取材に「あげるのは寄付という認識があり、預かってもらうという認識だった」と述べた。 木村によると、選挙事務所を閉鎖する際、当選祝いとして政治家や会社社長、在日大使館などから受け取ったコチョウランのうち大半を、市内の知人や病院など7カ所に預けた。「捨てるのが惜しまれた」「家が手狭だった」などと釈明した。知事公邸に入居後に「取りに行こうと思っている」とも語った<ref>{{Cite web |和書 |url=https://www.nikkei.com/article/DGXZQOUE0148C0R00C24A5000000/|title=熊本県知事、当選後にコチョウラン配る 「預けた認識」|work=日本経済新聞|date=2024-05-01|accessdate=2024-05-01}}</ref>。木村は同月10日の記者会見で「全て回収する話がついた」と述べた。既に2つを回収したという<ref>{{Cite news|url=https://www.sankei.com/article/20240510-HXW6PX3WX5M6NPTMYHBIS7DI2Y/|title=知人に譲渡のコチョウラン「回収めど」 熊本知事、違法性は否定|newspaper=産経新聞|date=2024-05-10|accessdate=2024-05-11}}</ref>。6月10日、全ての回収を完了したと明らかにし「預かってくださいと明示して渡した」と違法性を改めて否定した<ref>{{Cite news|url=https://www.sankei.com/article/20240610-5E6RDHEM7NO3FMU7HIGUPLEPEE/|title=「どうしても捨てたくなかった」 ラン回収終えた熊本知事、違法性を再度否定|newspaper=産経新聞|date=2024-06-10|accessdate=2024-06-14|archiveurl=https://web.archive.org/web/20240610102526/https://www.sankei.com/article/20240610-5E6RDHEM7NO3FMU7HIGUPLEPEE/|archivedate=2024-06-10}}</ref>。
* 2024年5月10日、懇談中に発言を遮られた水俣病の被害者団体が[[伊藤信太郎]]環境大臣に抗議した様子について「事実上、つるし上げになっていた。大臣も環境省も」と定例会見で発言した。直後に記者からの指摘を受け撤回した<ref>{{Cite web|title=発言遮られた水俣病患者団体らの抗議、熊本知事「つるし上げになっていた」…直後に陳謝|url=https://www.yomiuri.co.jp/national/20240511-OYT1T50025/|website=読売新聞オンライン|date=2024-05-11|access-date=2026-01-22|language=ja}}</ref>。
* 2024年8月20日に開かれた木村を本部長とする県の「『くまもとで働こう』推進本部」の初会合で、木村は「一般事務は要らない。そういう若者を育ててはいけない。（高校の）[[普通科 (学校)|普通科]]なんか要らないと思っている」と述べたという。木村は22日の会見で「人手不足の原因の一つに、求人が一般事務に偏っていることを言いたかった」と釈明。「事務職をなくすとか、普通科高校を撤廃するつもりは全くない。今後、発言にはしっかりと気を付ける」と述べ、「訂正しておわびしたい」と陳謝した<ref>{{Cite news|url=https://www.jiji.com/sp/article?k=2024082200790|title=熊本知事「普通科要らない」 人材確保巡り、会見で陳謝|newspaper=時事通信|date=2024-08-22|accessdate=2024-08-22}}</ref>。
* 2025年10月8日、福岡県で開かれた九州半導体産業展での講演に際し、TSMCの熊本進出に関して『[[肥後の引き倒し]]』という表現を用いて言及。また、地下水を大事にする県民性を『土着の宗教』と発言した<ref>{{Cite web|title=TSMC進出で「肥後の引き倒し」 地下水汚染や渋滞懸念に熊本知事、不安解消を強調|url=https://www.sankei.com/article/20251008-U7BZ3A4HGNO3DPNLTO3RL5EUH4/|website=産経新聞：産経ニュース|date=2025-10-08|access-date=2026-01-22|language=ja|last=産経新聞}}</ref>。同月10日、不適切であったとして発言を撤回した<ref>{{Cite web|title=地下水〝土着の宗教〟発言 熊本県知事が撤回「的確ではない表現であった」 {{!}} 熊本のニュース｜RKK NEWS｜RKK熊本放送 (1ページ)|url=https://newsdig.tbs.co.jp/articles/rkk/2222437|website=RKK熊本放送|date=2025-10-10|access-date=2026-01-22|language=ja}}</ref>。
* 2023年、熊本県の旅行支援事業の助成金問題に関する公益通報を行った人物が、ハラスメントを理由に減給3か月の懲戒処分を受けた。2026年1月20日、当時副知事だった木村と通報者とのやり取りが公表され「内情を暴露するのは逆にブーメランになって通報者を刺しに来るのが既得権・旧体制のやる手段」「あなたのおかげで悪だくみが止まった」などと発言していたことが公表された<ref>{{Cite web|title=「あなたのおかげで悪だくみが止まった」副知事が公益通報者に声掛け のちに懲戒処分されたのは“不当” と訴え 熊本県 {{!}} 熊本のニュース｜RKK NEWS｜RKK熊本放送|url=https://newsdig.tbs.co.jp/articles/rkk/2413225|website=RKK熊本放送|date=2026-01-20|access-date=2026-01-22|language=ja}}</ref><ref>{{Cite web|title=「不定期異動、懲戒…ありとあらゆる嫌がらせ受けた」公益通報めぐる不利益を訴え|url=https://www.kab.co.jp/news/article/16297311|website=KAB熊本朝日放送|access-date=2026-01-22|language=ja}}</ref>。
